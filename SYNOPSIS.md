# Project Synopsis

## Project Title
**CampusBot: Educational AI Chatbot using HTML, CSS and JavaScript**

## Programme
Bachelor of Computer Applications (BCA) — Final Year

## Introduction
A chatbot is a software application that interacts with users through text or voice. CampusBot is an educational chatbot prototype that provides predefined answers to introductory questions about computing and study practices through a conversational web interface.

## Problem Statement
Students often need quick access to introductory explanations and study guidance. A simple chatbot interface can demonstrate how users interact with a knowledge base through natural-language-like questions.

## Objectives
1. Design a responsive chatbot interface.
2. Accept user messages through a chat input.
3. Match keywords and phrases against a predefined knowledge base.
4. Display suitable responses and a fallback message.
5. Save chat history locally in the browser.
6. Design a MySQL schema for future server-side conversation storage.

## Proposed Technology
- HTML5: structure and form controls
- CSS3: responsive layout and interface styling
- JavaScript ES6: message handling, rule matching and DOM updates
- Browser localStorage: local chat history
- MySQL 8+: proposed database schema

## Scope
The delivered application is a client-side rule-based prototype. It can respond to selected educational topics and demonstrate a chatbot interaction. It is not a trained or generative AI model and does not connect to an external AI service or the MySQL schema.

## Modules
1. Chat User Interface
2. Message Input and Display
3. Keyword Matching Engine
4. Knowledge Base
5. Fallback Response Handler
6. Local Conversation History
7. MySQL Database Design

## Expected Outcome
A browser-based chatbot demonstration that runs without installation and illustrates basic conversational interaction and rule-based response selection.

## Future Enhancements
A server-side API, live MySQL persistence, admin knowledge-base editor, user accounts, multilingual support, intent classification, analytics and optional integration with a secure AI API.

## Conclusion
CampusBot provides a simple foundation for understanding chatbot interfaces, event handling, string normalization and rule-based response selection in web development.
