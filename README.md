# CampusBot — AI Chatbot (BCA Final Year Project)

## Project overview
CampusBot is a browser-based educational chatbot demonstration built with **HTML5, CSS3 and vanilla JavaScript**. It has a chat interface, predefined knowledge base, keyword/pattern matching, typing indicator, suggested prompts and browser-local chat history.

> Academic accuracy note: this is a rule-based chatbot prototype, not a generative AI model. It does not connect to ChatGPT, Gemini or any external AI API. The MySQL schema is a separate database-design deliverable; the static website does not connect to it.

## How to run
1. Extract the ZIP file.
2. Open the `BCA_AI_Chatbot` folder.
3. Open `index.html` in Chrome, Firefox, Edge or another modern browser.
4. Optional local server: open a terminal in the folder and run:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000`.

No packages or build tools are required.

## Features
- Chat-style responsive user interface
- Predefined knowledge base covering AI, ML, HTML, CSS, JavaScript, Python, DBMS and study tips
- Keyword and phrase matching for response selection
- Fallback response for unknown questions
- Suggested prompt buttons
- Typing indicator and timestamps
- Chat history stored in browser `localStorage`
- Start-new-chat and clear-history controls
- About dialog explaining the demo

## Database setup (optional)
The MySQL 8+ schema is in `database/schema.sql`. Import it with:
```bash
mysql -u root -p < database/schema.sql
```
The schema creates `chatbot_sessions`, `chat_messages` and `knowledge_base`. The current front-end application does not read or write these tables. A server-side API (for example, Flask, PHP, Java or Node.js) would be needed to connect the browser app to MySQL safely.

## Testing
Try prompts such as:
- What is artificial intelligence?
- Explain HTML and CSS.
- What is JavaScript?
- Give me exam preparation tips.
- Tell me a fun fact about computers.
- Ask an unrelated question to test the fallback response.

## Limitations and future scope
Current responses are selected from a small local knowledge base and are not generated by a trained language model. Future improvements could add a backend, MySQL persistence, admin knowledge-base management, user accounts, multilingual support, analytics, and integration with a vetted AI API. Any API key must be stored server-side, never in browser JavaScript.
